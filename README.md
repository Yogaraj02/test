# test

Eight simple standalone React frontend projects. No backend or API.

| Project | Folder to run |
| --- | --- |
| Student Management | Student-Management-Frontend/student-management |
| Employee Management | Employee-Management-Frontend/employee-management |
| Expense Tracker | Expense-Tracker-Frontend/expense-tracker |
| Item Management | Item-Management-Frontend/item-management |
| Library Management | library-management |
| Quiz App | Quiz-App-Frontend/quiz-app |
| To-Do List | To-Do-List-Frontend/todo-list |
| Trip Management | Trip-Management-Frontend/trip-management |

Open a terminal in the relevant project folder, then run:

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal. Each project has its own README with usage details. Data is stored in React state and resets on refresh.
