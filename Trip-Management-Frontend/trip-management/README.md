# Trip Management System

Simple React frontend only. No backend or API.

Extract the ZIP, open a terminal in the trip-management folder, and run:

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal. Requires Node.js 20.19+ or 22.12+ (Node 24 also works).

Enter a destination and select a date, then click Add Trip. Both fields are required. Trips appear under My Trips. Click Delete to remove a trip.

Data uses React useState; refreshing clears all trips. Main code: src/App.jsx.

To build: npm run build. To preview the build: npm run preview.
