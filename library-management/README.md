# Library Management System

Simple React frontend only. No backend or API.

Extract the ZIP, open a terminal in the library-management folder, and run:

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal. Requires Node.js 20.19+ or 22.12+ (Node 24 also works).

Enter a book title and author name, then click Add Book. Both fields are required. Books appear under Book List. Click Delete to remove a book.

Data uses React useState; refreshing clears all books. Main code: src/App.jsx.

To build: npm run build. To preview the build: npm run preview.
