# To-Do List

Simple React frontend. No backend or API.

Extract the ZIP, open a terminal in the todo-list folder, and run:

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal. Requires Node.js 20.19+ or 22.12+ (Node 24 also works).

Enter a task name and an optional description. Add Task creates a Pending task. Edit fills the form; Update Task saves changes. Delete removes a task. Change Status switches between Pending and Completed.

Data uses React useState; refreshing clears all tasks. Main code: src/App.jsx.

To build: npm run build. To preview the build: npm run preview.
